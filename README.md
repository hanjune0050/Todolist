# 📚 공부 타이머 (Study Timer)

아이패드에서 **오프라인**으로 혼자 쓰는 공부용 투두 · 타이머 앱입니다.
설치 없이 사파리에서 **"홈 화면에 추가"** 하면 앱처럼 아이콘이 생기고, 인터넷 없이도 동작합니다.
모든 데이터는 **기기 안(localStorage)** 에만 저장되며 서버로 전송되지 않습니다.

---

## 주요 기능

- **주간 캘린더** — 한 주를 한눈에. 날짜를 누르면 그 날의 할 일이 표시됩니다.
  - 각 날짜 칸에 그 날 할 일 수만큼 **미니 체크박스**가 생기고, 완료하면 색이 채워집니다.
  - 그 날 할 일을 **전부 완료**하면 날짜 칸이 초록색으로 강조됩니다.
- **날짜별 할 일** — 제목 · 색상 · 소요 시간 · 반복(없음/매일/매주) · 종료 날짜 설정.
  - 언제든 **수정/삭제** 가능(✏️ 버튼).
- **타이머** — 할 일을 누르면 설정한 소요 시간만큼 카운트다운.
  - **일시정지 → 이어서** 하거나 **처음부터** 다시 시작 가능.
  - **시간 연장**(+1분 / +5분 / +30분) — 모든 할 일에서 진행 중 시간을 늘릴 수 있어요.
  - 시간을 임의로 줄이는 기능은 없습니다(일반 할 일). 단, **모의고사 모드는 조기 종료** 가능.
  - 완료되면 자동으로 체크 + 제목에 취소선.
  - 체크박스를 직접 눌러 **수동 완료**도 가능합니다.
- **모의고사 점수 기록 & 추이** — 모의고사 모드 할 일을 끝내면 점수를 입력할 수 있고,
  **통계 → 모의고사 점수 추이**에서 할 일별 점수 변화를 꺾은선 그래프로 확인합니다(최근·최고·응시 횟수 포함).
  - **+ 점수 추가**로 앱으로 풀지 않은 지난 모의고사 점수(할 일·날짜·점수)도 직접 넣을 수 있고, 각 점수 칩의 ✕로 삭제할 수 있어요.
- **세로 타임테이블(08:30–24:00)** — 타이머로 공부한 구간이 **할 일 색상**으로 표시됩니다.
- **모의고사 모드** — 과목 선택 시 소요 시간 자동 설정.
  - 국어 80 / 수학 100 / 영어 50 / 화학 30 / 지구 30 (분)
  - **마킹시간 포함** 체크 시: 국어·수학 −3분, 화학·지구 −1분.
  - 과목마다 어울리는 파스텔 기본색이 자동 지정됩니다(직접 변경 가능).
- **월간 뷰** — 한 달을 한눈에. 날짜별 완료 수·공부 시간, 전부 완료한 날은 초록색. 날짜를 누르면 그 날로 이동.
- **통계** — 이번 주 / 이번 달 / 전체 기간별 **과목·할 일별 누적 공부 시간**(타이머로 실제 공부한 시간 기준).
- **완료음 · 진동** — 타이머 완료 시 소리와 진동(설정에서 끌 수 있음).
- **백그라운드 유지** — 앱을 잠깐 나갔다 오거나 화면이 꺼져도 타이머가 이어집니다(다시 열면 남은 시간 복원, 그 사이 끝났으면 자동 완료). 진행 중에는 화면이 자동으로 꺼지지 않습니다.
- **다크 모드** — 설정에서 전환(기본은 기기 설정 자동 감지).
- **백업 / 복원** — 설정에서 데이터를 파일로 내보내고 가져올 수 있어요. **사파리 데이터를 지워도** 백업 파일만 있으면 복원 가능.

## 아이패드에 설치하기 (오프라인 앱으로)

오프라인 PWA는 브라우저 보안 정책상 **HTTPS 주소**로 한 번 열어야 합니다.
가장 간단한 무료 방법은 **GitHub Pages** 입니다.

### 1) GitHub Pages 로 올리기
1. 이 저장소의 파일이 GitHub 에 올라가 있어야 합니다(현재 브랜치 그대로 사용 가능).
2. GitHub 저장소 → **Settings → Pages** 로 이동.
3. **Source** 를 `Deploy from a branch` 로 두고, 브랜치를 이 앱이 있는 브랜치(`claude/ipad-app-offline-2eiof2`) 또는 `main`, 폴더는 `/root` 로 선택 후 저장.
4. 잠시 후 나오는 주소(예: `https://hanjune0050.github.io/todolist/`)가 앱 주소입니다.

### 2) 홈 화면에 추가
1. 아이패드 **사파리**로 위 주소를 엽니다.
2. 공유 버튼(⬆️) → **"홈 화면에 추가"**.
3. 홈 화면에 생긴 **📚 공부 타이머** 아이콘으로 실행하면 전체 화면 앱처럼 열립니다.
4. 한 번 연 뒤에는 **비행기 모드/오프라인**에서도 그대로 동작합니다.

> 참고: 데이터는 그 기기의 사파리 저장소에 남습니다. 사파리 데이터를 지우면 할 일 기록도 삭제됩니다.

## 로컬에서 미리 보기 (선택)

컴퓨터에서 테스트하려면 이 폴더에서 간단한 서버를 띄우면 됩니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 파일 구조

```
index.html      화면 구조
styles.css      디자인
app.js          모든 기능(캘린더/할 일/타이머/타임테이블/모의고사)
manifest.json   PWA 설정(아이콘, 이름 등)
sw.js           오프라인 캐시(서비스워커)
icons/          앱 아이콘
fonts/          내장 폰트(Pretendard, 오프라인용)
tools/make_icons.py  아이콘 생성 스크립트
```

### 앱을 수정했다면
`sw.js` 안의 `const CACHE = 'study-timer-v1';` 의 버전을 올리세요(`v2`, `v3`…).
그래야 아이패드에서 새 버전이 반영됩니다.
